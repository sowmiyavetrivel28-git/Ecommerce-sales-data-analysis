# E-Commerce Sales Data Analysis

## Overview

In this project, I worked on an e-commerce sales dataset using Microsoft Excel. The main aim is to understand customer behavior and sales performance by doing data cleaning, analysis, and creating a dashboard.

---

## Dataset

The dataset contains details like:

* Customer (Gender, Age Group, Loyalty Level)
* Product (Category, Unit Price, Discount)
* Sales (Quantity, Total Amount)
* Region and Store Type

---

## Data Cleaning

* I handled missing values using average and category-wise average (AVERAGEIF)
* Removed duplicate data
* Formatted the dataset properly
* Merged multiple tables using XLOOKUP

---

## Analysis

* I calculated mean, median, mode, and standard deviation
* Created pivot tables for better understanding
* Compared sales based on category, gender, and region
* Analyzed customer segments like age group and loyalty level

## Key Insights

* Adult customers contribute the highest share of total sales.

* Female customers show slightly higher spending compared to male customers.

* Certain regions perform better in terms of sales, indicating strong regional demand.

* Category-wise pricing has a direct impact on total revenue.

* Higher discounts do not always result in higher sales, showing that pricing strategy matters.

* Loyal customers tend to purchase more frequently compared to new customers.

* Sales vary across different store types, indicating differences in customer preferences.
